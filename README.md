# IT 497 Professional Growth Portfolio

This repository contains the portfolio website and supporting documents.

## Publish with GitHub Pages
1. Upload/commit the updated repository files to the `main` branch.
2. In GitHub, open **Settings → Pages** and confirm the publishing source is the `main` branch and root folder.
3. Wait for the Pages deployment workflow to complete successfully.
4. Open the published website on desktop and on a phone, then test every navigation and document link.

## Accessibility and usability updates
- Added a skip-to-content link and semantic labels for navigation and main content.
- Added a visible current-page navigation state and keyboard focus indicators.
- Improved typography, contrast, spacing, and responsive layouts.
- Added mobile-friendly navigation wrapping and horizontally scrollable wide tables.
- Respects the operating system's reduced-motion preference.

Before submitting the 5.3 report, complete the manual checks described in the accompanying usability report. Do not report a test as completed unless it was actually performed.
